# 出力フォーマット例（Pythonの場合）
```python
def process_invoice_data(base_price: float, tax_rate: float, discount: float) -> float:
    """
    割引を適用した後に、商品の税込み合計金額を計算する。

    Args:
        base_price (float): 商品の税抜き基本価格
        tax_rate (float): 消費税率（例: 0.1）
        discount (float): 割引額

    Returns:
        float: 割引・税込み適用後の最終合計金額
    """
    # ── [ステップ1] 割引の適用 ──
    # 基本価格から割引額を差し引く（マイナスにならないよう制御）
    discounted_price = max(0.0, base_price - discount)
    
    # ── [ステップ2] 税込み金額の計算 ──
    # 割引後の価格に消費税を上乗せして最終金額を算出する
    final_amount = discounted_price * (1 + tax_rate)
    
    return final_amount
```
